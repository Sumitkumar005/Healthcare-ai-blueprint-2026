# 23. Nutrition Risk Screening

## 🎯 The Problem

Malnutrition increases hospital length of stay and costs but is often undetected. Nutrition screening is required but nurses skip it due to time constraints. Need quick, validated screening tool.

**Impact**: 
- Saves 5-10 minutes per screening
- Early detection of malnutrition risk
- Automatic dietitian referral

## 💡 The Solution

Quick nutrition screening tools (MST/MUST) with automatic score calculation, risk stratification, and automatic dietitian referral for high-risk patients.

## 🚀 Quick Start

```bash
cd 23-nutrition-risk-screening
pip install -r requirements.txt
python src/main.py
```
