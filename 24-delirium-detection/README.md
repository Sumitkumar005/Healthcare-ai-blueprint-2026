# 24. Delirium Detection Tool for Post-Op Patients

## 🎯 The Problem

Delirium affects 30-50% of elderly surgical patients but is often missed or detected late. Confusion Assessment Method (CAM) is the gold standard but requires consistent application.

**Impact**: 
- Early delirium detection
- Better patient outcomes
- Reduced complications

## 💡 The Solution

Guided CAM assessment tool with automatic delirium detection, risk factor identification, and intervention recommendations.

## 🚀 Quick Start

```bash
cd 24-delirium-detection
pip install -r requirements.txt
python src/main.py
```
