# 27. Patient Acquisition Cost Tracker

## 🎯 The Problem

Medical practices spend on Google Ads, Facebook, and other marketing channels but have zero attribution data. Don't know which channels bring valuable patients or ROI.

**Impact**: 
- Tracks CAC (Customer Acquisition Cost) per channel
- Calculates LTV (Lifetime Value) by source
- Optimizes marketing budget allocation
- Improves ROI by 20-40%

## 💡 The Solution

Track patient source during intake, calculate acquisition costs, analyze lifetime value, and provide ROI dashboard by marketing channel.

## 🚀 Quick Start

```bash
cd 27-patient-acquisition-cost
pip install -r requirements.txt
uvicorn src.main:app --reload
```
