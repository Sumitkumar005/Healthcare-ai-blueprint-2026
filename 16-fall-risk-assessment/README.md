# 16. Fall Risk Assessment Tool

## 🎯 The Problem

Fall risk assessment is required for elderly patients but nurses use paper checklists. No trending over time or proactive intervention planning. Morse Fall Scale is standard but manual scoring is time-consuming.

**Impact**: 
- Saves 5-10 minutes per assessment
- Enables trend tracking
- Automatic intervention recommendations

## 💡 The Solution

Digital Morse Fall Scale assessment tool with automatic score calculation, risk stratification, and intervention recommendations.

## 🚀 Quick Start

```bash
cd 16-fall-risk-assessment
pip install -r requirements.txt
python src/main.py
```

## 📊 Features

- Digital Morse Fall Scale questionnaire
- Automatic score calculation (0-125)
- Risk stratification (Low/Medium/High)
- Intervention recommendations
- Trend tracking
