# 29. Patient Satisfaction Survey Analyzer

## 🎯 The Problem

Practices collect patient feedback but data sits unused. Don't know how to operationalize comments into actionable improvements.

**Impact**: 
- Extracts themes from free-text comments
- Generates prioritized action items
- Tracks improvement over time

## 💡 The Solution

AI-powered survey analyzer that extracts themes, performs sentiment analysis, and generates actionable improvement plans.

## 🚀 Quick Start

```bash
cd 29-patient-satisfaction
pip install -r requirements.txt
uvicorn src.main:app --reload
```
