# 31. Referral Network Performance Tracker

## 🎯 The Problem

Primary care providers refer patients by habit, not data. Don't know which specialists provide better outcomes.

**Impact**: 
- Tracks referral performance metrics
- Scores specialists on multiple dimensions
- Guides referral decisions with data

## 💡 The Solution

Track referrals, monitor completion rates, collect feedback, and score specialists to guide referral decisions.

## 🚀 Quick Start

```bash
cd 31-referral-network
pip install -r requirements.txt
uvicorn src.main:app --reload
```
