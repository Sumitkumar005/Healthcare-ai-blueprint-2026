# 09. Supply Order Intelligence for Small Practices

## 🎯 The Problem

Practices order supplies from multiple vendors reactively. No price comparison or usage tracking leads to **15-25% overspending**.

**Impact**: 
- Reduces supply costs by 15-25%
- Prevents stockouts
- Optimizes inventory

## 💡 The Solution

Intelligent supply management system that tracks usage, predicts reorder timing, compares prices across vendors, and generates optimized purchase orders.

## 🚀 Quick Start

```bash
cd 09-supply-order-intelligence
pip install -r requirements.txt
python src/main.py
```
